# Changelog

Versies volgen SemVer: **major.minor.patch**.

- Major: ingrijpende game- of savewijzigingen.
- Minor: nieuwe gameplayfuncties die compatibel blijven.
- Patch: bugfixes, prestaties en visuele correcties.
