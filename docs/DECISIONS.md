# Design decisions

## v0.9.0 direction

- Movement combines accessible arcade control with light inertia.
- Camera smoothly follows the ship.
- The first gameplay loop combines exploration, salvage and later light combat.
- Helix Station is a safe starting area with few enemies.
- The player starts as an independent explorer.
- Multiplayer architecture is prepared but not activated.
- Each galaxy receives a unique game-like art direction.
- v0.9.0 starts a new development save.
- Priorities: movement/camera, reliable menu/map, planets/backgrounds.
- All game content and interface text are English only.
